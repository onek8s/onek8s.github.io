# Lab examples

The test applications the lab runs, one page per isolation zone and one section per application. They
describe what Git deploys to the lab, not what a cluster runs at a given moment.

Generated by the documentation agent of [onek8s/aks-ai-agents](https://github.com/onek8s/aks-ai-agents) (`aks-agent docs lab`) from Git alone: aks-terraform's cells, the landing zone's firewall rule files, the fleet's zones and allow-lists, the applications' Flux configuration and their source repositories. Do not edit by hand - aks-terraform's Lab examples workflow regenerates it.

These pages are not part of the requirements or the design, and they are in neither PDF.
