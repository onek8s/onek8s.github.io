# 8.1 Release notes

**Requirements:** none - the version history of the design.

The design is versioned, one minor version per pull request that changes it and a major version only when a human
says so, newest first; every version is tagged `v<version>` in every repository. Only the current major version is
listed here: the older versions are in the Git tags, the last before v4.0 being
[`v3.8`](https://github.com/onek8s/onek8s.github.io/tree/v3.8). The version is shown in the site's
header and on the covers of the [PDFs](https://github.com/onek8s/onek8s.github.io/blob/main/CONTRIBUTING.md#the-pdf-and-the-release-notes)
([how to add an entry](https://github.com/onek8s/onek8s.github.io/blob/main/CONTRIBUTING.md#the-pdf-and-the-release-notes)).

## v4.0 - 2026-10-20

- Requirements-driven collaboration: the requirements and acceptance criteria are in `requirements/`, owned by humans
  (part 0, page 0.1 How we work), and the design is in `design/`, owned by AI; a required Approvals check asks a human
  to approve a change to `requirements/` and the AI to review a change to `design/`
  ([#109](https://github.com/onek8s/onek8s.github.io/pull/109)).
- The requirement texts of 1.2 are page 0.2 and design 1.2 shows how the design meets each of them; the acceptance
  tests of 7.1 are page 0.3 ([#109](https://github.com/onek8s/onek8s.github.io/pull/109)).
- What no requirement names moved to the unpublished `archive/`: the pages 7.1 Implementation project and acceptance
  testing, 7.4 Outlook and the options kept open and 7.5 Other clouds, sovereignty and exit (its data services
  joined 1.3), and sections of 1.0, 1.2, 2.3 (GPUs), 4.1, 5.1, 5.2, 6.2, 7.2 and 7.3
  ([#109](https://github.com/onek8s/onek8s.github.io/pull/109)).
- Every design page names the requirements it serves under its title, and `check.sh` checks it
  ([#109](https://github.com/onek8s/onek8s.github.io/pull/109)).
- Two PDFs: the design with every design page, the summary first, and the requirements
  ([#109](https://github.com/onek8s/onek8s.github.io/pull/109)).
