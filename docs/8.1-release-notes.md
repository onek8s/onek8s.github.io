# 8.1 Release notes

The design is versioned from v1.0 on, one minor version per pull request that changes it, newest first; the version
is shown in the site's header and on the covers of the [PDFs](https://github.com/onek8s/onek8s.github.io/blob/main/CONTRIBUTING.md#the-pdf-and-the-release-notes)
([how to add an entry](https://github.com/onek8s/onek8s.github.io/blob/main/CONTRIBUTING.md#the-pdf-and-the-release-notes)).

## v1.13 - 2026-10-19

- Git refs instead of an OCI artifact (D77): a pull request is the only way into a branch, GitHub's merge signature is
  verified by Flux and the stateful pipeline, every cell follows a branch of its own that the release pipeline moves,
  the placement is read from `main`; section 3.3 and its picture say so once, the pages that leaned on the artifact
  follow ([#94](https://github.com/onek8s/onek8s.github.io/pull/94)).

## v1.12 - 2026-10-18

- The README's table of repositories is gone; the onek8s organisation lists them
  ([#93](https://github.com/onek8s/onek8s.github.io/pull/93)).

## v1.11 - 2026-10-18

- Editing the pictures and the site leaves the published design for `CONTRIBUTING.md` on GitHub; these release notes
  are 8.1, the appendix's only page ([#92](https://github.com/onek8s/onek8s.github.io/pull/92)).

## v1.10 - 2026-10-18

- The Wolkwacht comparison leaves the published design for `reviews/` on GitHub; the appendix renumbers: editing the

## v1.9 - 2026-10-18

  and the section that explains it; the README and the Summary send application teams there first
