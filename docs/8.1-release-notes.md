# 8.1 Release notes

The design is versioned, one minor version per pull request that changes it and a major version only when a human
says so, newest first; every version is tagged `v<version>` in every repository. The version is shown in the site's
header and on the covers of the [PDFs](https://github.com/onek8s/onek8s.github.io/blob/main/CONTRIBUTING.md#the-pdf-and-the-release-notes)
([how to add an entry](https://github.com/onek8s/onek8s.github.io/blob/main/CONTRIBUTING.md#the-pdf-and-the-release-notes)).

## v2.0 - 2026-10-19

- Azure CNI Overlay is removed: every cell is Azure CNI Pod Subnet with Cilium, and section 5.2 compares only who
  decides egress (D74, D61, D79) ([#97](https://github.com/onek8s/onek8s.github.io/pull/97)).
- AKS Automatic is removed with option E; D75 is retired ([#97](https://github.com/onek8s/onek8s.github.io/pull/97)).
- The dev lab is one cell, `aks-dev-int-stateless-az3` (Sweden's `int-se`); az1 and az2 are gone
  ([#97](https://github.com/onek8s/onek8s.github.io/pull/97)).
- Zone nodes are classic node pools with the cluster autoscaler; node auto provisioning stays out until it supports
  the pod subnet (a watch list row in 7.4) ([#97](https://github.com/onek8s/onek8s.github.io/pull/97)).
- Every repository is tagged with the design version (`v<version>`) by aks-terraform's `Design tags` workflow
  ([#97](https://github.com/onek8s/onek8s.github.io/pull/97)).

v1.0 to v1.15 are in the [v1.15 tag](https://github.com/onek8s/onek8s.github.io/tree/v1.15/docs/8.1-release-notes.md).
