# 7.3 Open questions

The former list of open questions has been worked through: each item is now a recorded decision with its
justification, a verification the dev lab or acceptance performs, or a question only a human can answer. The
[decision log](7.2-decisions.md) holds all three. This page keeps only what still needs a person, so that it can be
read as the sign-off list for the [connection readiness gate](7.1-implementation-project-and-acceptance-testing.md#connection-readiness-gate).

([decision log](7.2-decisions.md#human-sign-offs-still-needed) for the defaults and the decisions behind them). H01, the
country boundary, was answered by the security team on 2026-10-14 ([D52](7.2-decisions.md#decision-matrix)).

## Assumptions still to be proven

No decision to make: the [capability matrix](7.2-decisions.md#azure-capability-and-verification-matrix) lists every
Azure feature the design relies on, what the dev lab has already proven, what phase 3 still has to show, and the
fallback if it fails. The ones not yet proven at all are V02 (NAP image pinning), V13 (`SecurityPatch` on a network
isolated cluster – whose documentation now lists only `NodeImage` and `None`), V16 (vault-tier backup with Cross Region
Restore in the chosen regions), V17 (Grafana Cloud Private Link across regions), V18 (Chaos Mesh with eBPF host
routing), V19 (Inspektor Gadget and Image Cleaner; kube-bench is proven), V21 (VNet encryption on every allowed VM family in
the region) and V22 (a hub and Firewall per exposure – the lab's firewall VM stands in for Azure Firewall, and there
is no external hub).

## Recently added features not yet adopted

Kubernetes 1.36 (April 2026), 1.37 (August 2026, AKS GA October 2026) and AKS's 2026 releases were reviewed on
2026-10-18 against the [rule for adding a feature](7.4-outlook-2030-and-the-options-kept-open.md#keep-it-simple-the-rule-for-adding-a-feature)
([D64](7.2-decisions.md#decision-matrix)). What passed is in the design ([D67](7.2-decisions.md#decision-matrix): idle
volumes in the stateful cluster; node pool rollback in [section 3.5](3.5-zero-downtime-cluster-upgrades.md#stateful-cluster);
`externalIPs` denied in [section 2.7](2.7-policy-enforcement.md); the 1.37 checklist V26). What failed for good is in
the [options kept open](7.4-outlook-2030-and-the-options-kept-open.md#the-options-kept-open). The rows below are
the ones a person has to decide, each with the design's default until then and what would settle it.
