# 8.3 Release notes

The design is versioned from v1.0 on; the version is shown in the site's header and on the cover of the
[PDF of the whole design](https://onek8s.github.io/onek8s-design.pdf), which is rebuilt with every publish. Every pull
request that changes the design adds a version here: the next minor version (v1.1, v1.2, ...) with one short sentence
per change and the link to the pull request, newest first, and the same version in `version:` of `_config.yml`. A
major version (v2.0) is a human's call. `scripts/check.sh` fails when the newest version here and `_config.yml`
disagree, or when an entry has no pull request link ([section 8.2](8.2-editing-the-pictures.md#the-pdf-and-the-release-notes)).
