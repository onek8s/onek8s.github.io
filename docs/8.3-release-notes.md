# 8.3 Release notes

The design is versioned from v1.0 on, one minor version per pull request that changes it, newest first; the version
is shown in the site's header and on the covers of the [PDFs](8.2-editing-the-pictures.md#the-pdf-and-the-release-notes)
([how to add an entry](8.2-editing-the-pictures.md#the-pdf-and-the-release-notes)).

## v1.7 - 2026-10-18

- The requirements table says how in one sentence per row and points to the section; the WAF add-on, the namespace
  groups' vault rights and the release-note rule are stated once; section 8.1 keeps the comparison and drops its
  changelog of closed gaps and the list of posts read and ignored
  ([#88](https://github.com/onek8s/onek8s.github.io/pull/88)).

## v1.6 - 2026-10-18

- Section 7.4 names a feature once: the watch-list rows the options table already carried (KMS data encryption, Image
  Integrity, AKS Automatic, IPv6, fleet scale) are folded into the options' triggers, and the trend table drops the rows
  that were options ([#87](https://github.com/onek8s/onek8s.github.io/pull/87)).

## v1.5 - 2026-10-18

- Lab anecdotes and status logs in one sentence each (5.3's first run, 7.1's CIS scores, the agents' and
  observability's "dev lab, today"), the verified HTTP/2 and TLS 1.3 state in 4.1, and the gateway implementation named
  as D70 left it - Traefik in every environment until App Routing can match it
  ([#86](https://github.com/onek8s/onek8s.github.io/pull/86)).

## v1.4 - 2026-10-18

- The decision log's longest rows keep the options, the decision and the why, and lose the built-state narration the
  sections already hold; the rows are in numeric order again and the capability matrix drops the lab's dates
  ([#85](https://github.com/onek8s/onek8s.github.io/pull/85)).

## v1.3 - 2026-10-18

- The cell's network mode is stated once per page: the pod-subnet default in sections 2.1, 2.3, 3.1, 5.1 and 5.2, the
  deprecated overlay as one note about the lab's az2, and the history of D73, D74 and D76 only in the decision log
  ([#84](https://github.com/onek8s/onek8s.github.io/pull/84)).

## v1.2 - 2026-10-18

- One list of human sign-offs: section 7.2's table gains H14 and H15 and is the only one; section 7.3 keeps the open
  questions Q01-Q07 alone, and the review-process notes left the decision log
  ([#83](https://github.com/onek8s/onek8s.github.io/pull/83)).

## v1.1 - 2026-10-18

- az3 is rebuilt as the pod-subnet cell of D74 and the user's layout amends D74: nodes and load balancers in /24 slots
  of one address space (az3: 10.100.0.0/16), pods in /20s of a second, a /16 of 100.64.0.0/10; classic zone pools with
  the cluster autoscaler, 250 pods a node; the legacy node-subnet notes are gone; the Dapr trial is off
  ([#78](https://github.com/onek8s/onek8s.github.io/pull/78)).

## v1.0 - 2026-10-18

- The first numbered version: the design as reviewed up to
  [#81](https://github.com/onek8s/onek8s.github.io/pull/81) (overlay deprecated for cells, D76), with these release
  notes and the whole design as one PDF, linked from the top of every page and built with every publish
  ([#82](https://github.com/onek8s/onek8s.github.io/pull/82)).
